# User-supplied Generation 9 sprites

Original sheet provided by Kai, attributed to Ezerart in its filename. This is user-supplied artwork, separate from PKHeX's upstream assets and the GPL-licensed application code. No additional artwork license is asserted here.

142 regular and 142 matching shiny 32×32 cells are extracted without scaling, recoloring, or alpha changes. The manifest records each species, form and source cell. Main rows are National Dex 906–1025; the Maushold entry there is Family of Four (form 1), while the lower alternate is Family of Three (form 0). Lower rows add Paldean Tauros/Wooper, Bloodmoon Ursaluna, and other alternate forms. Blank cells are excluded. The matching shiny sheet is included with its own shiny-manifest.json and uses an `s` suffix on sprite filenames. The editor, storage slots, and library select those names when the Pokémon’s Shiny flag is set.

The original PNG is retained here for attribution and reproducibility. Outputs live in ../Sprites and use the existing sprite lookup names. Dudunsparce uses its form-specific icon instead of the upstream default-form shortcut.
