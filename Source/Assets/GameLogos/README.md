# Game identity artwork

47 PNGs are bundled. Yellow’s white background was removed with the built-in imagegen tool; its subtitle retains white lettering. `sources.json` retains source pages and image URLs. Logos remain property of their respective rights holders; KeepSake is unofficial.

`SaveGameLogo` selects the save's game (including Ranch), supports grouped game versions, and displays individual Black/White and Black 2/White 2 identities. For early Red, Blue/Green, Gold, Silver, Crystal, Box and some Stadium formats, English title text is composed beneath the Pokémon wordmark. These native lockups are not exact English game-logo reproductions; the original Japanese assets are retained in this folder. Unknown versions retain a named wordmark fallback.
