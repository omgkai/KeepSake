# Trainer-card badge artwork

Original user-supplied sheets, copied byte-for-byte:

- `classic.png`: **16x16 Pokemon Badge Sprites: Gen 1–6**, JcFerggy, source filename `16x16_pokemon_badge_sprites_gen_1_6_by_jcferggy_d9006sy.png`. The sheet includes Kanto, Johto, Hoenn, Sinnoh, Unova (including Toxic/Wave), Kalos and additional anime badges. Only the matching game badges are used. This sheet does not supply Galar art.
- `paldea.png`: **Paldea Badges demake large**, ProfessorMorDBG, source filename `paldea_badges_demake_large_by_professormordbg_diwbwzy.png`. Gym, Titan and Team Star badges.

`manifest.json` records 68 source rectangles in top-left pixel coordinates. KeepSake crops these at runtime with nearest-neighbor rendering; it does not repaint the originals. Earned artwork uses full opacity, with an accessible earned label and checkmark. Unearned artwork is faded. Unknown or ambiguous save records say “Not recorded”. Galar uses a native seal fallback; Alola and Hisui have native passport/rank marks.

These supplied fan-art files have separate authorship from KeepSake’s source license; no additional license grant is implied.
